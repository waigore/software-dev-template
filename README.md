# software-dev-template
Template repo for agent-driven software development projects

## Start here

After creating a repo from this template, ask your agent to:

1. Run `ensure-project-setup` to check and complete first-time GitHub setup.
2. Run `capture-requirements` to lock in the high-level requirements: the vision, then the definition (scope, platforms, stack, spec depth), then quality expectations. Product and every other spec build on these. You can describe the product in as much detail as you like up front; product-level detail is saved as notes and used when product is captured.
