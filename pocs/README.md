# `pocs/`

Proofs of concept: one folder per PoC, kept apart from the main code. Main code never imports from here.

Product demo mode (limited full product) is not here—see [`docs/demo.md`](../docs/demo.md) and [`specs/product/demo.md`](../specs/product/demo.md).

Contract: [`docs/pocs.md`](../docs/pocs.md). Log requests in [`docs/requirements/poc-requests.md`](../docs/requirements/poc-requests.md). Scope with `scope-poc`; build with `create-poc`.
